# StockNote 交易日记 — 产品与技术规格 (v0.2)

> 状态：已确认 · 日期：2026-11-13 · 范围：Android MVP（预留 Windows 端与云同步）
>
> v0.2 变更：标的扩展到 A 股 + ETF + 板块；多数据源（Tushare Pro 为主）；AI 默认 DeepSeek；新增持仓与交易模块（手动 / 图片 / 表格导入）；日记与判断可事后修改并保留修改历史；判定阈值多级可调。

---

## 1. 产品定位

一款面向 A 股个人交易者的**交易日记**应用。核心闭环：

```
看盘（大盘实时 + AI 分析） → 记录（快速、自动分条） → 验证（到期自动对答案） → 复盘（统计自己哪类判断靠谱）
```

与普通笔记的区别：每条日记都会**自动绑定当时的行情快照**，并可附带一个**可验证的判断**，到期后系统自动拉取实际行情判定对错，长期积累出“我的判断准确率画像”。

### 1.1 目标用户
- 有一定经验的 A 股短线 / 波段交易者
- 习惯盘中随手记想法，但事后很少系统复盘

### 1.2 标的范围
- A 股个股（沪、深、北交所）
- 场内 ETF（含 LOF）
- 板块：行业板块、概念板块（以板块指数形式参与行情展示、判断与验证）
- 大盘指数

所有标的统一抽象为 `Instrument { code, name, type: stock|etf|index|sector, exchange }`，日记关联、判断、持仓都基于它。

### 1.3 非目标（MVP 不做）
- 不做下单 / 券商实盘对接（只记录交易，不执行交易）
- 不提供投资建议，AI 分析仅为辅助参考（App 内需有免责声明）
- 不做社区 / 分享
- 不做港股、美股、期货（数据层预留扩展）

## 3. 功能详细说明

### 3.1 大盘看板（首页 Tab 1）

**3.1.1 实时数据**
- 指数卡片：上证指数、深证成指、创业板指、沪深 300、科创 50、北证 50（可配置顺序/显隐）
  - 最新点位、涨跌幅、涨跌点、成交额
  - 点击进入分时 / 日 K 详情
- 市场宽度：上涨 / 下跌 / 平盘家数，涨停 / 跌停家数，炸板率
- 两市总成交额，与昨日同时段对比（放量/缩量）
- 板块热度：行业 / 概念涨幅榜 Top 10 与跌幅榜 Top 10，点击进入板块详情（板块指数走势 + 成分股涨跌）
- ETF：热门 / 自选 ETF 行情，含成交额与溢价率（数据源支持时）
- 自选列表：个股、ETF、板块混合自选
- 刷新策略：交易时段内前台每 5 秒（可配置 3–30 秒）；非交易时段停止轮询，显示收盘数据
- 交易日历：内置 A 股交易日历（节假日休市），用于判断是否交易日及 T+N 计算

**3.1.2 AI 大盘分析**
- 触发方式：
  - 手动：看板上“AI 分析”按钮
  - 定时（可开关）：9:35（开盘后）、11:35（午间）、15:05（收盘）
- 输入：当前指数数据、市场宽度、成交额对比、板块排行、近 N 日指数 K 线摘要、（可选）用户最近日记中的观点
- 输出（要求模型返回 JSON，App 渲染为卡片）：
  ```json
  {
    "sentiment_score": 62,          // 0-100 市场情绪
    "trend": "震荡偏强",            // 强势上涨/震荡偏强/震荡/震荡偏弱/弱势下跌
    "key_levels": {"support": [3280, 3250], "resistance": [3350]},
    "highlights": ["成交额较昨日放大 12%", "半导体领涨"],
    "risks": ["高位股炸板率上升"],
    "outlook": {"horizon": "T+1", "direction": "up", "confidence": 0.6},
    "summary": "一段 100 字以内的总结"
  }
  ```
- **AI 判断也可验证**：`outlook` 字段自动生成一条“AI 判断”记录，与用户判断走同一套验证流程，可在统计里对比“我 vs AI”准确率
- 历史分析列表可查看、可一键引用到日记
- 模型配置：设置页填写 API Key，**默认 DeepSeek**（`deepseek-chat`，可切换 `deepseek-reasoner`）；各任务（大盘分析 / Agent / 图片识别 / 表格映射）可分别选模型
  - 内置预设：DeepSeek、通义千问、Kimi、智谱 GLM、Anthropic Claude、OpenAI
  - 自定义：任意 OpenAI 兼容接口（base URL + model + key）
  - 可为不同任务分别指定模型：大盘分析 / 图片识别（需支持视觉的模型）/ 表格字段映射
- 失败处理：网络/Key 错误时提示，不阻塞看板

### 3.2 日记记录（Tab 2，核心）

**3.2.1 数据结构：日 → 时段 → 条目**
- 每个交易日一页“日记本”
- 条目按 **交易时段自动分组**（自动时点分条）：

  | 时段 | 时间 |
  |---|---|
  | 盘前 | 00:00 – 09:15 |
  | 集合竞价 | 09:15 – 09:30 |
  | 早盘 | 09:30 – 11:30 |
  | 午间 | 11:30 – 13:00 |
  | 午盘 | 13:00 – 14:57 |
  | 尾盘 | 14:57 – 15:00 |
  | 盘后 | 15:00 – 24:00 |

  非交易日的记录归入“周末/假日复盘”，并关联到下一个交易日。
- 每条条目自动带：精确时间戳、所属时段、**当时的行情快照**（主要指数点位/涨跌幅、成交额、涨跌家数；若关联个股则加个股价格）

**3.2.2 快捷输入**
- 首页常驻悬浮按钮 + 桌面小组件（Widget）+ 通知栏快捷入口，**一步打开输入框**
- 输入框为单行起步、可展开；回车即保存为一条（连续回车 = 连续分条）
- 输入框上方**只有一排四个按钮**：一级 / 二级 / 标签 / 快捷，按钮显示当前选择（如 判断 · 个股 · 看多·T+1）；点击按钮在其上方弹出与 `$` 联想同样式的**匹配列表**：一级选中后自动展开二级，二级选中后自动展开标签（其余二级选项 + 情绪，分组单选），快捷点选即插入短语
- **二级分类**（v0.3）：

  | 一级 | 含义 | 二级展开 |
  |---|---|---|
  | 观察 | 对现象的描述与分析，可针对某个目标，也可以是新闻 | 主题：盘面 / 板块题材 / 个股 / 消息新闻 / 资金 / 其他 |
  | 判断 | 对某个对象的多空判断（M3 可自动验证） | 对象：大盘 / 指数 / 板块题材 / 个股 / ETF；方向：看多 / 看空 / 震荡；周期：今日 / T+1 / 本周 / 中期 |
  | 计划 | 预计近期 / 未来买卖股票或 ETF | 动作：买入 / 加仓 / 减仓 / 卖出；时间：今日 / 近期 / 未来 |
  | 复盘 | 事后总结 | 类型：当日 / 交易 / 判断 / 其他 |
  | 其他 | 任意内容 | 无 |

  - 未选一级分类时保存为“其他”；连续记录时保留上次的一级分类，二级与情绪清空
  - 判断未选对象但正文 `$` 关联了标的时，按标的类型自动补全对象
  - 输入框提示随分类变化，引导写出对象、方向、理由
  - 情绪（可选，任意分类）：冷静 / 犹豫 / FOMO / 恐慌 / 贪婪（用于后续情绪 vs 胜率分析）
  - 自定义常用短语（设置中管理，如“放量突破”“缩量回调”“冲高回落”）
- 行内语法（可选，熟手用）：
  - `$` → 关联标的：输入 `$`（或中文输入法的 `￥`）后弹出匹配列表，覆盖指数 / 板块题材 / ETF / 个股，按代码、名称、拼音首字母匹配，点选插入 `$名称`（回车选第一项）；选中项记住代码避免同名歧义
  - `#标签` → 标签
  - `>3350 T+1` → 快速创建可验证判断（见 3.3）
- 语音输入：调用系统语音识别转文字
- 图片：可附截图（K 线、盘口），本地存储
- 模板：盘前计划模板、盘后复盘模板（可自定义字段）
- 编辑：条目与判断**均可事后修改**，每次修改生成一条修改记录（修改前快照、修改时间、修改字段），可查看历史版本与差异
  - 条目上显示“已修改 N 次”标记
  - 判断若在**到期前被修改**，标记为“已修改判断”；统计页可切换“按原始判断统计 / 按最终判断统计 / 排除修改过的判断”，保证复盘诚实

**3.2.3 浏览**
- 日视图：时间轴形式展示当天所有条目，每条旁显示快照中的指数涨跌
- 日历视图：月历，每天用颜色标示当日判断准确率 / 盈亏
- 搜索：全文 + 标签 + 股票 + 观点 + 结果过滤

### 3.3 回溯与验证（Tab 3）

**3.3.1 可验证判断（Prediction）**
条目可附 0..N 个判断，结构化字段：

| 字段 | 说明 | 示例 |
|---|---|---|
| 标的 | 指数 / 个股 / ETF / 板块 | 上证指数 / 600519 / 510300 / 半导体板块 |
| 方向 | 上涨 / 下跌 / 震荡 | 上涨 |
| 周期 | 当日收盘 / T+1 / T+3 / T+5 / 自定义日期 | T+1 |
| 目标价（可选） | 达到即正确 | 3350 |
| 止损/失效价（可选） | 触及即错误 | 3280 |
| 震荡区间（方向=震荡时） | 上下界 | 3280–3350 |
| 信心度 | 1–5 | 3 |

基准价 = 创建时的快照价格。

**实现（v0.3，M3）**
- 判断由“判断”类日记**自动生成并保持同步**（一条日记一条判断）：对象 → 标的（大盘默认上证指数，其余取 `$` 关联的第一个标的），方向 看多 / 看空 / 震荡，周期 今日 / T+1 / 一周(T+5) / 中期(T+20)，未选周期默认 T+1
- 目标价、止损价、阈值覆盖、信心度在判断详情页填写
- 时间窗口：盘前 / 盘中记录以当天为 T；盘后记录“今日”顺延到下一交易日，基准为当天收盘；周末 / 假日记录以下一交易日为第一个交易日
- 记录时没取到快照：基准价按前一交易日收盘估算（盘后记录取当日收盘）
- 验证调度：App 启动、打开复盘页、运行期间每 10 分钟检查；到期日 15:30 后、且到期日 K 线已更新才判定。后台定时任务 + 通知放到 M7（WorkManager）

**3.3.2 自动判定规则**
到期后（到期交易日收盘后 15:30 起）由后台任务拉取行情并判定：
- 仅方向：到期收盘价 vs 基准价，变动幅度超过阈值算对应方向，阈值内算“震荡”
- **阈值多级可调**，优先级：单条判断覆盖 > 标的类型默认 > 全局默认
  - 默认值：指数 ±0.3%、板块 ±0.5%、ETF ±0.5%、个股 ±1.0%；也可按周期（T+1 / T+5）分别设置
  - 修改全局阈值后可选择“仅影响新判断”或“重新判定历史”（重新判定会记录 `rule_version`）
- 有目标价/止损价：用周期内日 K 的最高/最低价判断**先触及哪个**（同日都触及则标为“不确定”，需手动判定）
- 结果：✅ 正确 / ❌ 错误 / ➖ 部分（方向对但未达目标）/ ❓ 待手动
- 记录实际涨跌幅、最大有利/不利波动（MFE/MAE）
- 用户可覆盖自动结果，但会标记“手动修改”

**3.3.3 复盘**
- 到期的判断进入“待复盘”队列，通知提醒
- 复盘时并排展示：当时的原文 + 当时快照 + 实际走势小图 + 自动结果
- 可写复盘笔记、标记原因（如“逻辑对但时机错”“情绪化”“消息面突变”）

- 实现：复盘页 待复盘 / 进行中 / 全部 / 统计 四个分页，复盘 Tab 显示待复盘数量角标；判断详情页含原文与快照、判定结果、K 线（标出记录日与到期日）、手动判定、复盘原因多选 + 笔记

**3.3.4 K 线回放**（待做：M7）
- 在指数/个股日 K 或分时图上，用标记点展示历史日记条目和判断；点击标记查看原文
- 时间轴拖动回放某一天：分时图 + 当天日记按时间逐条出现

**3.3.5 统计**
- 总体准确率、近 30 日趋势
- 维度拆分：按观点、标的、周期、时段、情绪、信心度、标签
- 信心度校准：信心 5 的判断是否真的比信心 2 准
- 我 vs AI：同周期判断准确率对比
- 已实现（M3）：正确率 / 方向正确率、按方向 / 对象 / 周期 / 信心度拆分、“排除到期前修改过的判断”开关；近 30 日趋势、按原始判断重算、我 vs AI 待后续

### 3.4 持仓与交易（Tab 4）

**3.4.1 交易记录**
- 字段：账户、标的、方向（买入 / 卖出 / 分红 / 送转 / 申购等）、成交时间、价格、数量、金额、佣金、印花税、过户费、备注
- 每笔交易可关联日记条目（“为什么买 / 为什么卖”），日记中记录买卖动作时可一键生成交易草稿
- 支持多账户（如不同券商）

**3.4.2 三种录入方式**
1. **手动输入**：标的联想、价格默认填当前价、数量快捷按钮（100 / 500 / 1000 / 全部）、费用按账户费率自动计算
2. **图片识别**：上传券商 App 成交记录 / 持仓截图
   - 流程：端上 OCR（Google ML Kit 中文识别）提取文字 → LLM 结构化为交易 / 持仓 JSON →（若配置了视觉模型可直接走视觉模型）→ **预览确认页**逐条核对后入库
3. **表格导入**：CSV / Excel（券商导出的交割单、成交明细）
   - 自动识别常见券商格式；未知格式提供列映射界面（可让 AI 推荐映射），映射方案可保存复用
   - 导入前去重（按时间 + 标的 + 价格 + 数量）

**3.4.3 持仓与盈亏**
- 由交易流水推导持仓（也支持直接导入 / 录入持仓快照用于初始化与对账）
- 成本算法：摊薄成本（默认）/ 移动加权平均，可切换
- 指标：持仓市值、浮动盈亏、当日盈亏、已实现盈亏、仓位占比、持有天数
- 统计：每笔交易结果、胜率、盈亏比、按标的 / 板块 / 月份汇总；与日记情绪、观点交叉分析（如“FOMO 状态下买入的胜率”）
- 交易与持仓也可修改，同样保留修改历史

### 3.5 全局 Agent 助手

一个贯穿全 App 的 AI 助手，能读取 App 内全部数据（大盘、日记、判断与验证结果、持仓交易、历史 AI 分析），提供分析与建议，有长期记忆，支持长期多轮对话。

**3.5.1 入口与上下文**
- 所有页面右下角都有全局入口（日记页与快捷输入按钮错开），另有独立的对话列表页
- **感知当前页面**：在某天日记页打开就自动带上“当天日记”作为上下文，在个股详情页打开就带上该标的，在复盘页打开就带上当前判断
- 常用指令快捷卡片：“今天盘面怎么看”“复盘我本周的判断”“我最近哪类判断最不准”“检查我的持仓风险”“总结我 FOMO 时的交易表现”

**3.5.2 能力（工具调用）**
Agent 通过 function calling 按需查询本地数据，而不是一次性把所有数据塞进提示词：

| 工具 | 说明 |
|---|---|
| `get_market_overview` | 当前指数、宽度、成交额、板块排行 |
| `get_quotes` / `get_kline` | 任意标的实时报价、K 线 |
| `search_journal` | 按日期 / 关键词 / 标签 / 标的 / 情绪检索日记 |
| `get_predictions` / `get_prediction_stats` | 判断明细、准确率统计（可按维度拆分） |
| `get_positions` / `get_trades` / `get_pnl_stats` | 持仓、交易流水、盈亏统计 |
| `get_ai_analyses` | 历史 AI 大盘分析及其验证结果 |
| `get_revisions` | 某条记录的修改历史 |
| `memory_search` / `memory_save` | 检索 / 写入长期记忆 |
| `draft_journal_entry` / `draft_prediction` | **起草**日记或判断，用户在确认卡片上点“保存”才写入 |

- 数据默认**只读**；任何写操作都必须经用户在确认卡片上确认
- 工具调用过程在对话中折叠展示（“查询了 3 月以来的 42 条日记”），可展开查看
- 回答中引用到的日记 / 判断 / 交易可点击跳转

**3.5.3 记忆**
- **长期记忆**：关于用户本人的稳定信息，分类为：交易风格、个人规则（如“不追涨停”）、偏好、经验教训、关注标的
  - 来源：对话中 Agent 主动提议保存（用户确认）、用户说“记住……”、每次对话结束后自动提炼候选记忆（进入待确认列表）
  - 记忆管理页：查看、编辑、置顶、删除；每条显示来源对话
  - 检索：MVP 用关键词 + 分类 + 重要度 + 最近使用时间排序；后续可加向量检索
  - 每轮对话自动注入置顶记忆 + 与问题相关的 Top-N 记忆
- **对话记忆**：多会话（thread）永久保存；会话过长时自动把早期消息压缩成滚动摘要，保留最近 N 轮原文，实现无限长对话
- 跨会话：新会话可通过 `memory_search` 和 `search_journal` 回忆以往内容

**3.5.4 主动能力（可开关）**
- 盘后自动生成“今日复盘”：汇总当天日记、判断、交易，并与大盘对照，指出与个人规则冲突的地方（如记忆里写了“不追高”，今天却追高买入）
- 每周总结：判断准确率变化、情绪分布、交易表现

**3.5.5 模型与隐私**
- 使用 AI 设置中的“Agent”任务模型（默认 DeepSeek，需支持 function calling）
- 数据权限开关：可分别允许 / 禁止 Agent 读取持仓交易、日记原文等；关闭的类别对应工具不可用
- 首次使用提示：数据会发送到所选模型服务商
- 免责：建议仅供参考，不构成投资建议

## 4. 非功能需求

- **离线优先**：所有日记本地可用，无网络时可记录（快照标记为“缺失”，联网后可补拉当时价格）
- **快**：冷启动到可输入 < 1.5 s；从 Widget 点击到可输入 < 1 s
- **隐私**：数据默认仅存本地；API Key 存 Android Keystore 加密
- **备份**：一键导出 / 导入（JSON + 图片打包 zip），支持导出 Markdown
- **省电**：后台仅在交易日定时唤醒（WorkManager），不常驻轮询
- **兼容**：Android 8.0 (API 26) 及以上；支持深色模式；A 股习惯红涨绿跌（可切换）

| 图表 | fl_chart（分时/统计）+ 自绘 K 线组件或 k_chart | |
| 网络 | dio | |
| 后台任务 | workmanager | 定时 AI 分析、到期判定 |
| 通知 | flutter_local_notifications | |

备选：Kotlin Multiplatform + Compose Multiplatform（Android 原生体验更好，Windows 走 JVM 桌面）。若更看重安卓原生体验可切换，数据模型不变。

### 5.2 架构

```

  data/

```

### 5.3 行情数据源（多源可插拔）
- 定义 `MarketDataSource` 接口，按能力拆分：`QuoteProvider`（实时报价）、`KlineProvider`（日 K / 分钟线）、`BreadthProvider`（市场宽度）、`SectorProvider`（板块列表、成分、排行）、`InstrumentProvider`（代码表、ETF 列表）、`CalendarProvider`（交易日历）
- 实现：
  - **Tushare Pro（默认首选）**：token 放在项目 `.env`（不入库），构建时 `--dart-define-from-file=.env` 注入；App 内也可另行设置覆盖
    - 实时：`rt_k` 个股（通配符拉全市场）、`rt_idx_k` 沪深指数、`rt_etf_k` ETF
    - 由全市场实时行情计算涨跌家数、涨停 / 跌停 / 炸板；成交额 = 上证指数 + 深证综指
    - 东财板块：`dc_index`（列表 / 盘后排行）、`dc_member`（成分）、`dc_daily`（日 K）
    - 基础：交易日历、代码表（个股 / ETF / 指数 / 板块）、日 K —— 也是验证判定的**权威来源**
  - **免费实时源**（腾讯 / 东方财富网页接口）：Tushare 不提供的**当日分时**、**板块实时排行**，以及各项的备用源
  - 退避按“数据源 + 能力”分别计算，某个接口失败不影响同源其他能力
  - 后续可加：自建服务端代理、其他付费源
- 设置页可为每种能力配置**数据源优先级**，失败自动 fallback；显示各源健康状态
- Tushare 积分 / 频率限制：客户端做请求节流与本地缓存（代码表、交易日历每日更新一次，日 K 增量拉取）
- ⚠️ 免费源为非官方接口，可能变更 → 适配层隔离，出错时降级到下一源

### 5.4 AI 分析
- `LlmProvider` 接口：`chat(messages, {json, images})`；上层用例：`analyzeMarket`、`parseTradeImage`、`suggestColumnMapping`
- 实现：`OpenAiCompatibleProvider`（覆盖 DeepSeek / 通义 / Kimi / GLM / OpenAI / 自定义）+ `AnthropicProvider`
- 提示词模板版本化存储（`prompt_version` 字段），便于比较不同版本提示词的准确率
- 要求结构化 JSON 输出，解析失败时重试 1 次，仍失败则保存原文
- 记录 token 用量，设置页展示
